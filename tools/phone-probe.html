② File System Access API 能力探测

这一节决定"能不能复用现有代码"（路线 A）。注意：FSA 是安全上下文 API，若不是 HTTPS，本节结论一律记为"无法判定"而不是"不支持"。

③ 真机读写实测（选一个 NAS 目录）

会在你选的目录里创建 __snap_probe__ 开头的临时文件/目录，测完立即清理；不会碰你的任何图片。
如果系统选择器里能看到 NAS（SMB）目录，说明手机里装了把 SMB 注册成文档提供者的 App（如 RSAF）。

③b 跨目录移动实测（分类操作的本质 · 最关键）

分类 = 把文件从「待分类」移到「目标」。③ 只证明"能写"，③b 才证明"能移动"。
会分别测试原生 move() 与现有代码的"复制+删源"回退路径，并检查源文件是否真的消失。需先完成 ③。

④ 图片加载速度

用 <img> 加载，不需要目标站允许跨源（WebDAV 没有 CORS 头，用 fetch 必然失败、还会把 401 错误页算成图片字节）。 判据：单张原图 <1s 可接受；>2s 则"服务端缩略图"是必需项。

⑤ 汇总（复制回传）

若"复制"按钮无效（HTTP 下剪贴板 API 被禁用），请长按上面的文本框手动全选复制。
