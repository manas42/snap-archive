# Snap Archive — 图片快速分类器

纯本地、无后端、键盘 + 鼠标驱动的图片人工分类器。把「待分类」文件夹拖进左边画布，把最多 20 个「分类目标」文件夹拖进右侧（外加 1 个固定 `Del` 槽位），然后一路快速归类。

## 环境要求

- **Chrome / Edge**（需要 File System Access API，用于真正移动文件）
- 无需安装任何依赖，无后端

> 为什么必须走 localhost：浏览器的 `showDirectoryPicker` / 文件夹写入 API 只在安全上下文（`https` 或 `http://localhost`）下可用，直接双击 `index.html`（`file://`）无法移动文件。

## 启动

```bash
node server.js
```

浏览器打开 **http://localhost:8000**（默认端口，可用 `PORT=8080 node server.js` 修改）。也可用 `python3 -m http.server 8000`。

## 使用步骤

1. **左侧画布**：拖入「待分类」文件夹（或点击选择）。空态是整幅拖放区，拖入后整幅变为预览画布。只读取该文件夹内、不含子文件夹的图片。
2. **右侧**：把目标文件夹拖到任意槽位，或一次性拖入多个（按顺序填充，最多 20 个）。前 10 个槽位有数字快捷键 `0–9`，第 11–20 个槽位无快捷键、仅鼠标点击分类。`Del` 槽位固定，不参与排序、也不会被批量填充，需单独拖入。
3. 开始分类：

| 按键 | 作用 |
| --- | --- |
| `空格` / `→` | 预览下一张 |
| `←` | 预览上一张（跳过） |
| `0`–`9`（小键盘） | 把当前图片移动到对应目标文件夹 |
| `Del` | 把当前图片移动到固定 `Del` 文件夹 |
| `Ctrl`+`Z` | 撤销上一次移动 |

**鼠标**：单击已填充的目标卡牌 = 同样触发分类；单击空卡牌 = 选择文件夹；拖动卡牌到另一卡牌 = 互换位置（把文件夹放到指定槽位）；点卡牌右侧的红色竖条 = 移除该文件夹。

## 支持格式

`bmp` · `jpg/jpeg` · `png` · `gif`（动态图）· `webp` · `webm`（视频）· `avif`

## 持久化与清空

- 所有拖入/选择的文件夹句柄保存在 **IndexedDB**（`snap-archive`），下次打开页面自动恢复（浏览器已授权时静默恢复）。
- 若上次的文件夹需要重新授权，顶部会显示「恢复」横幅，点击即可重新授权。
- 「清空所有」按钮清空全部配置与已保存的文件夹引用（**不会改动磁盘上的任何文件**）。

> 说明：之所以用 IndexedDB 而非 localStorage，是因为浏览器出于安全考虑不暴露文件夹的真实路径，且 `FileSystemDirectoryHandle` 无法序列化为字符串——只有 IndexedDB 能存这类句柄对象。

## 权限说明

- 拖入/选择文件夹时浏览器会请求「读取 + 写入」权限，请允许——移动文件需要写源文件夹（删除原文件）和目标文件夹（写入新文件）。
- 目标文件夹若存在同名文件，会自动重命名为 `原名 (1).ext` 避免覆盖。
- 撤销（`Ctrl+Z`）会把最近一次移动的文件移回原文件夹。

## 文件结构

```
index.html   页面结构
style.css    样式（深色主题、80%/20% 布局、卡牌竖条删除）
app.js       核心逻辑（拖放、目录读写、预览、键盘/鼠标操作、IndexedDB 持久化）
server.js    极简本地静态服务器（无依赖）
```
