# Snap Archive — 图片快速分类器

纯本地、无后端、键盘 + 鼠标驱动的图片人工分类器。把「待分类」文件夹拖进左边画布，把最多 20 个「分类目标」文件夹拖进右侧（外加 1 个固定 `Del` 槽位），然后一路快速归类。

> **本仓库有两套实现，本 README 讲的是桌面版**
>
> | 实现 | 入口 | 形态 |
> | --- | --- | --- |
> | **桌面版**（下文） | [`webapp/`](webapp/)：`index.html` + `app.js` + `style.css` + `server.js` | 依赖浏览器 File System Access API，操作本机/映射盘上的文件夹 |
> | **手机版** | [`mobile/index.html`](mobile/index.html)（单文件、零依赖） | 手机浏览器直接操作局域网 NAS 上的文件；页面与 NAS 的 WebDAV 同源，用 `PROPFIND/MOVE/COPY/DELETE` 干活，配置存在 NAS 上同目录的 `snap-config.json` |
>
> 两套实现**互相独立、不共享任何代码**：桌面版全部在 `webapp/` 下，手机版就是 `mobile/index.html` 这一个文件（详见[仓库结构](#仓库结构)）。
>
> 手机版的**设计说明**见 [`design/DESIGN.md`](design/DESIGN.md)，**测试用例**见 [`tests/TEST-CASES.md`](tests/TEST-CASES.md)（怎么跑见 [`tests/README.md`](tests/README.md)），部署脚本为 [`tools/deploy-webdav.sh`](tools/deploy-webdav.sh)。

## 环境要求

- **Chrome / Edge**（需要 File System Access API，用于真正移动文件）
- 无需安装任何依赖，无后端

> 为什么必须走 localhost：浏览器的 `showDirectoryPicker` / 文件夹写入 API 只在安全上下文（`https` 或 `http://localhost`）下可用，直接双击 `webapp/index.html`（`file://`）无法移动文件。

## 启动

```bash
node webapp/server.js
```

浏览器打开 **http://localhost:8000**（默认端口，可用 `PORT=8080 node webapp/server.js` 修改）。也可用 `cd webapp && python3 -m http.server 8000`。

## 使用步骤

1. **左侧画布**：拖入「待分类」文件夹（或点击选择）。空态是整幅拖放区，拖入后整幅变为预览画布。只读取该文件夹内、不含子文件夹的图片。载入后预览为**三联对比**：中间是当前图，左侧上一张、右侧下一张（按 75% 缩小并减淡）；点击两侧缩略图只做前后切换、不会归类，首尾没有相邻图时该侧留空。
2. **右侧**：把目标文件夹拖到任意槽位，或一次性拖入多个（从落点槽位起依次填入**空槽位**，已填充的槽位不会被覆盖，最多 20 个）。同一个目录**不会重复添加**：已经占了某个槽位（或 `Del` 槽）的文件夹再次拖入/选择会被跳过并提示它当前所在的槽位；批量拖入时批次内重复的也只会保留第一个。**源文件夹本身也不能加入目标区**（同一个目录既当源又当目标，等于把文件移回自己），反之把一个已在目标区的文件夹设为源也会被拒绝。前 10 个槽位有数字快捷键 `0–9`，第 11–20 个槽位无快捷键、仅鼠标点击分类。`Del` 槽位固定，不参与排序、也不会被批量填充，需单独拖入。
3. 开始分类：

| 按键 | 作用 |
| --- | --- |
| `空格` / `→` | 预览下一张 |
| `←` | 预览上一张（跳过） |
| `0`–`9`（小键盘） | 把当前图片移动到对应目标文件夹 |
| `Del` | 把当前图片移动到固定 `Del` 文件夹 |
| `Ctrl`+`Z` | 撤销上一次移动 |

**鼠标**：右上角的「↶ 撤销」按钮等同于 `Ctrl+Z`（无操作可撤销时置灰）；单击已填充目标卡牌的**主体区域**（文件夹名 / 计数）= 同样触发分类，单击空卡牌主体 = 选择文件夹；卡牌右侧操作区（快捷键角标、`⇄`/`▦`/`✕`）**不会**触发分类，避免误触移动；拖动卡牌到另一卡牌 = 互换位置（把文件夹放到指定槽位）；点卡牌右侧的红色竖条 = 移除该文件夹。移动/分类时当前图片会缩小飞入目标槽位（纯视觉动画，不影响撤销）。

**交换**：已填充目标卡牌上的 `⇄` 按钮 = 把该文件夹与源文件夹互换（原源文件夹进入该槽位，撤销栈随之重置）。固定 `Del` 槽位同样支持。

**删除空文件夹**：源文件夹里的待分类文件全部处理完后，顶栏会出现「🗑 删除空文件夹」按钮，点击即用浏览器原生的 `FileSystemHandle.remove()` **直接删掉这个已清空的目录**（只对空目录生效，非空会抛 `InvalidModificationError`，因此绝不会误删内容），不弹任何选择窗口、也不需要父文件夹句柄；`Del` 槽位没指定文件夹也不影响。若目录里还剩东西（被「仅图片/仅视频」过滤排除的文件、子文件夹等），会先弹确认，把它们整体搬进右侧 `Del`（丢弃）槽位的文件夹后再删除该目录（此时才需要 `Del` 槽位已指定文件夹）。删除后源文件夹状态与记录一并清空，`Ctrl+Z` 不能恢复这一步。

**图集**：顶栏源文件夹旁的「图集」按钮以 5×4 栅格分页浏览源文件夹的全部图片（打开时定位到当前图片所在页）；点击任意缩略图即关闭模态框并跳到该图片继续分类；`Esc` / 点击遮罩可关闭。底部可切换「新 → 旧 / 旧 → 新」（按修改时间排序，**默认新到旧**，选择会记住）；源文件夹预览与图集共用同一条文件顺序。已填充目标卡牌上的 `▦` 按钮同样打开图集，但为**只读预览**（标题标注「只读」，点击缩略图不跳转）。

## 支持格式

`bmp` · `jpg/jpeg` · `png` · `gif`（动态图）· `webp` · `webm`（视频）· `mp4`（视频）· `avif`

## 源文件类型过滤

载入源文件夹后，顶栏源信息旁可选择「**图片+视频 / 仅图片 / 仅视频**」：过滤即时重扫源目录并保留当前文件位置（若仍符合过滤），预览、图集与数字快捷键都作用于过滤后的列表；选择会被记住，下次打开自动沿用。

## 视频播放

- **自动播放开关**（顶栏「自动播放」勾选，会记住）：控制主图视频载入后是否自动播放；左右预览图**总是不自动播放**，只显示首帧。
- 主图与左右预览的视频格中央都有 **▶ 图标**标识其为视频；主图播放中图标变为半透明 **⏸**。
- **点击主图画面**可切换播放 / 暂停（点击底部原生控件条不会触发切换）；主图视频自带**进度条、音量**等原生控件。
- 视频（`webm`/`mp4`）在主位带控制条播放；左右缩略与图集网格只显示首帧。

## 持久化与清空

- 所有拖入/选择的文件夹句柄保存在 **IndexedDB**（`snap-archive`）。
- 打开页面时**不会静默恢复**：顶部会显示一条横幅（只点出上次的源文件夹名），点「恢复」才把全部文件夹载入；点「暂不」则本次跳过，记录保留、下次打开仍会询问。
- 恢复时若浏览器已授权则直接载入，否则会弹出授权请求；拒绝授权的文件夹本次跳过（记录保留），句柄已失效的会被自动清除。旧版本可能把同一个目录存进两个槽位，恢复时这类重复记录会被自动清理。
- 「清空目标」按钮移除全部目标文件夹（20 个普通槽位 + 固定 Del 槽），源文件夹与撤销栈保留；「清除缓存」按钮清空浏览器中保存的全部文件夹记录并重置界面（两者都**不会改动磁盘上的任何文件**）。

> 说明：之所以用 IndexedDB 而非 localStorage，是因为浏览器出于安全考虑不暴露文件夹的真实路径，且 `FileSystemDirectoryHandle` 无法序列化为字符串——只有 IndexedDB 能存这类句柄对象。

## 权限说明

- 拖入/选择文件夹时浏览器会请求「读取 + 写入」权限，请允许——移动文件需要写源文件夹（删除原文件）和目标文件夹（写入新文件）。
- 目标文件夹若存在同名文件，会自动重命名为 `原名 (1).ext` 避免覆盖。
- 撤销（`Ctrl+Z`）会把最近一次移动的文件移回原文件夹。

## 仓库结构

仓库按**实现**分目录，桌面版与手机版各占一个，互不引用：

```
webapp/                 桌面版（就是本 README 讲的这套）
  index.html            页面结构
  style.css             样式（深色主题、80%/20% 布局、卡牌竖条删除）
  app.js                核心逻辑（拖放、目录读写、预览、键盘/鼠标操作、IndexedDB 持久化）
  server.js             极简本地静态服务器（无依赖）

mobile/
  index.html            手机版：单文件、零依赖，直连 NAS 的 WebDAV

design/
  DESIGN.md             手机版设计文档（由实现反推）

tests/
  TEST-CASES.md         手机版手工测试用例集（122 条）
  README.md             用例怎么跑：环境准备、执行顺序、收尾清理

tools/
  deploy-webdav.sh      手机版部署脚本（把 mobile/index.html PUT 到 NAS 的 WebDAV）
```

手机版在 NAS 上的落点是一个专用目录（下文示例统一写作 `/pool-a/snap-archive-app/`）：应用页 `index.html` 与自动生成的 `snap-config.json` 都在这一层，配套测试语料放在它的 `test/` 子目录里。
